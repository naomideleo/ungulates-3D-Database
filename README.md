# 🦏 Enhancing & Digitizing Italian Theriological Collections
### An open-access 3D database of terrestrial ungulate skulls

![Status](https://img.shields.io/badge/status-in%20progress-yellow)

## About the project
This project delivers an open-access 3D database of terrestrial 
ungulate skulls digitized across the major Italian natural history 
collections, funded by the **PNRR – National Biodiversity Future Center**.

Specimens are digitized using structured-light scanning (Artec Spider) 
and photogrammetry, and analysed with geometric morphometrics (GMM).

## Collections involved
| Museum | City |
|--------|------|
| Museo La Specola (MZUF) | Florence |
| Museo Civico di Zoologia | Rome |
| Museo di Anatomia Comparata | Rome |
| Museo Regionale di Scienze Naturali (MRSN) | Turin |
| Museo di Storia Naturale "Giacomo Doria" (MSNG) | Genoa |

## Current status
- 🟡 350+ specimens digitized across 5 museums
- 🟡 ~206 species — 13/13 families covered
- 🟡 Landmark dataset and GMM analyses: ongoing
- 🟡 3D models upload to MorphoSource: coming soon
